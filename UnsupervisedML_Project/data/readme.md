# Dataset

The dataset used in this project was obtained from **Kaggle**. It contains customer demographics, purchasing behaviour, and spending information, which were used for customer segmentation.

**Dataset Source:** [Smart Cart Customer Dataset](https://www.kaggle.com/datasets/tusharbiswas77/smartcart-customer-dataset/data)

**Note:** The dataset file is not included in this repository. Download it from the original source and place it in this `data/` directory before running the notebook.
